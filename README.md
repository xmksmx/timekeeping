# табель учёта рабочего времени

учебный проект по объектно-ориентированному программированию.

используются java 25 и maven.

## модули

- model — библиотека классов предметной области.
- demo — консольное приложение.

## сборка

из корневой папки проекта: `mvn clean verify`.

## запуск в windows

`java -cp "demo/target/classes;model/target/classes" Main`
